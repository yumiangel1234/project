# TRD — 현장별 공정·기성 대시보드

## 한눈에 보기

- Next.js + TypeScript로 만드는 PC 웹 앱입니다. 자료 검사·계산·CSV 만들기는 브라우저에서, AI 호출만 서버에서 합니다.
- 계산은 화면과 분리한 TypeScript 함수로 만들어, Vitest(계산이 맞는지 자동으로 확인하는 도구)로 `data/검산표.md`의 숫자와 대조합니다.
- AI는 Gemini API(모델 `gemini-3.8-flash`)를 서버에서만 호출하고, API 키는 `.env.local`에만 둡니다.
- 서버 저장·데이터베이스가 없어 새로고침하면 자료를 다시 가져와야 합니다. 월 비용은 0원(무료 구간)입니다.
- 구현 결과 반영: 차트는 외부 라이브러리 없이 직접 만든 SVG, CSV 읽기는 직접 구현, Gemini는 REST 직접 호출로 정했습니다(아래 표·AI 결정 목록에 표시).
- `design/` 폴더는 구현 시점에도 비어 있었습니다(맨 아래 "확인이 필요한 점").

기준 문서: `실습조건.md`, `작업규칙.md`, `01_PRD.md`, `02_FRD.md`, `data/데이터설명.md`, `data/검산표.md`. `(AI 결정)`은 실습조건에 정해져 있지 않아 제가 정한 항목입니다.

| AI 연결 | REST 직접 호출(서버의 `fetch`, `src/lib/aiServer.ts`) — **구현 결과**, 공식 패키지는 쓰지 않음 | 호출이 한 곳뿐이라 추가 패키지 없이 충분하고, 키는 요청 헤더로만 보냅니다. | AI 결정 |
| 패키지 관리 | npm, 버전은 설치 시점의 안정 버전 | Node.js와 함께 설치되어 별도 가입·설치가 없습니다. | AI 결정 |
| 지원 브라우저 | PC의 최신 Chrome·Edge | PRD가 "PC 브라우저에서 쓰는 웹 앱"입니다. | PRD |

실습조건 규정: GitHub·Vercel·Gemini 외의 서비스 가입을 요구하지 않습니다. 위 도구는 모두 설치형 패키지이며 가입이 필요하지 않습니다.

## 5. 자료가 어디서 어디로 가는지

| 순서 | 어디서 | 어디로 | 무엇이 | 서버를 거치나 |
|---|---|---|---|---|
| ① | 사용자 PC의 파일(CSV·JSON) | 브라우저 | 파일 내용을 읽음 | 아니요 |
| ② | 브라우저 | 브라우저 메모리 | 검사 통과한 144행으로 전체 교체 (오류·취소면 기존 자료 유지) | 아니요 |
| ③ | 브라우저 메모리 | 화면 | 필터 적용 후 계산한 큰 숫자·순위·추이·막대·비교표 | 아니요 |
| ④ | 브라우저 메모리 | 사용자 PC | 같은 범위의 CSV 파일 내려받기 | 아니요 |
| ⑤ | 브라우저 | 우리 서버 `/api/ask` | 질문, 범위, 선택 월 원문 행, 계산 지표, 월별 요약 (API 키는 포함하지 않음) | 예 |
| ⑥ | 우리 서버 | Gemini API | 지시문 + 위 자료 + API 키(서버에서만 붙임) | 예 |
| ⑦ | Gemini API | 우리 서버 → 브라우저 | 답변 | 예 |
| ⑧ | 브라우저 | AI 페이지 | 범위가 바뀌지 않았을 때만 답변과 근거 표시 | 아니요 |

- 가져온 파일 전체는 서버에 보내지 않습니다. AI 질문 때만 현재 범위의 필요한 부분이 서버와 Gemini로 갑니다. 이 자료는 교육용 가상 자료입니다.
- 서버는 받은 내용을 저장하지 않습니다.

## 6. AI 호출 방법

| 항목 | 내용 | 정한 이유 |
|---|---|---|
| 호출 위치 | `POST /api/ask` 서버 코드에서만 | API 키 노출 방지 (실습조건) |
| 받는 내용 | 질문(최대 500자), 범위, 원문 행, 계산 지표, 월별 요약, 월별 원문 기록(현장 한 곳일 때) | FRD 6장 |
| 받은 내용 검사 | 형식·길이를 검사하고, 전체 크기가 약 100KB를 넘으면 거부 (AI 결정) | 잘못된 요청과 과도한 전송을 막습니다. 12개 현장 자료는 이보다 훨씬 작습니다. |
| 지시문(시스템 지시) 핵심 | ① 전달된 숫자만 근거로 설명, 직접 계산·정정 금지 ② `issueSummary`는 "기록된 상황", `actionPlan`은 "계획된 대응"으로만 설명, 원인·완료·효과 단정 금지 ③ 자료에 없는 내용(실제 준공일·미수금·기상 실측)은 "자료 없음"으로 답하고 `contractEndDate`는 계약상 일정으로 구분 ④ 범위 밖의 월·현장은 전달된 범위를 안내 ⑤ 답변에 기준 월·현장·근거 숫자·참고한 기록 필드 표시 | FRD 기능 15·17, 작업규칙 "자료와 근거를 다루는 방법" |
| 응답 형태 | 답변 글 + 근거(기준 월·현장·숫자·참고 필드)를 나눠 받습니다. | 화면의 "답변과 기준 월·현장·근거 숫자·기록 필드"를 따로 표시하기 위해서입니다. |
| 제한 시간 | 20초 | FRD 기능 15 |
| 오류 구분 | API 키 없음 / 사용 한도 초과 / 시간 초과 / 연결 실패 / 응답 형식 오류 → 각각 쉬운 말 한 줄 | 사용자가 원인을 구분하고 "대시보드·CSV는 계속 쓸 수 있습니다"를 확인하도록 합니다. |
| 오래된 응답 | 요청마다 범위 번호를 붙이고, 돌아온 응답의 번호가 현재 범위와 다르면 버립니다. 이 처리는 브라우저에서 합니다. | 필터 변경 후 이전 범위의 늦은 답변이 새 범위에 보이면 안 됩니다. |
| 모의 응답 | 환경 변수 `AI_MOCK`으로 켭니다. `ok`는 모의 답변("모의 응답" 표시), `nokey`·`quota`·`timeout`·`error`·`connection`은 해당 실패 응답을 만듭니다. 켜면 실제 Gemini를 부르지 않습니다. (AI 결정) | 실제 API를 쓰지 않고도 화면·오류 동작을 확인할 수 있고, 실제 성공으로 오인되지 않게 합니다. |
| 서버가 더 계산해 보내는 값 | 점검 순위(`inspectionRanking`)와 전월 대비 공정차이 변화(`progressGapChange`)를 프로그램이 계산해 함께 전달합니다. (구현 중 추가, AI 결정) | 첫 실제 호출에서 AI가 공정차이 숫자를 빠뜨리거나 단위를 "%p"로 쓰고 변화량을 언급하지 않았습니다. AI에게 계산을 맡기지 않는다는 원칙대로, 필요한 값을 프로그램이 미리 계산해 넘기도록 바꿨습니다. |
| 모델 이름 | `gemini-3.8-flash`를 그대로 사용 | 실습조건에 정해진 값입니다. 실제 호출에서 받아들여지는 것을 확인했습니다(`docs/05_테스트결과.md`). |

## 7. API 키 보관 방법

| 규칙 | 내용 |
|---|---|
| 키를 받는 곳 | 강사가 나눠 줍니다. |
| 넣는 곳 | 프로젝트 폴더의 `.env.local` 파일에 학습자가 직접 넣습니다. 변수 이름은 `GEMINI_API_KEY` (AI 결정) |
| 코드에서 읽는 곳 | 서버 코드(`/api/ask`)에서만 읽습니다. 이름을 `NEXT_PUBLIC_`으로 시작하게 하지 않습니다(그러면 브라우저에 노출됨). |
| 대화·화면·로그 | AI(저)는 키 값을 대화에 출력하지 않습니다. 화면과 오류 메시지, 서버 로그에도 키를 남기지 않습니다. |
| GitHub | `.env.local`을 `.gitignore`에 넣어 올라가지 않게 합니다. 코드에는 키를 적지 않습니다. |
| 키가 없을 때 | 서버가 "API 키 없음"을 알리고, 대시보드·CSV는 계속 동작합니다. |
| 배포 서버 | 배포 서버의 환경 변수는 따로 넣습니다. 이 TRD 단계에서 등록하지 않습니다. |

## 9. 실행 방법

| 순서 | 할 일 | 명령 또는 행동 |
|---|---|---|
| ① | Node.js(JavaScript를 PC에서 실행하는 프로그램) 설치 확인 | 이 PC에서는 아직 확인되지 않았습니다. 없으면 LTS(장기 지원) 버전을 설치합니다. |
| ② | 필요한 패키지 설치 | `npm install` |
| ③ | API 키 넣기 | 프로젝트 폴더에 `.env.local`을 만들고 `GEMINI_API_KEY=강사가_준_키`를 적습니다. |
| ④ | 앱 실행 | `npm run dev` 후 브라우저에서 `http://localhost:3000` 열기. 포트가 겹치면 다른 번호를 씁니다(예: `npm run dev -- -p 3001`). 이미 실행 중인 다른 프로그램은 끄지 않습니다. |
| ⑤ | 자동 검사 | `npm test` |
| ⑥ | 배포용 빌드 확인 | `npm run build` |
| ⑦ | 자료 가져오기 | 앱의 "자료 가져오기"에서 `data/현장공정기성.csv` 또는 `.json`을 고릅니다. |

새로고침하면 가져온 자료가 사라지므로 ⑦을 다시 합니다(PRD "하지 않는 것").

## 10. 배포 방법 (안내만, 실행은 별도 요청 후)

실습조건: GitHub 저장과 Vercel 배포는 사용자가 따로 요청하기 전에는 실행하지 않습니다. 이 TRD를 읽은 것은 실행 요청이 아닙니다.

| 단계 | 내용 | 시작 조건 |
|---|---|---|
| GitHub 저장 | 비공개 저장소에 코드를 올립니다. `.env.local`은 올리지 않습니다. | 사용자가 저장소 주소를 지정하고 "이 저장소에 올려 줘"라고 요청한 경우만. Vercel 배포를 포함하지 않습니다. |
| Vercel 배포 | 저장소를 연결하고 `GEMINI_API_KEY`를 Vercel 환경 변수에 넣은 뒤 배포합니다. | 사용자가 STEP 11에서 직접 하거나, 배포할 프로젝트·저장소를 정해 별도로 요청한 경우만. |
| 자동 배포 | GitHub 변경만으로 배포되는 연동 | 사용자 요청 전에는 추가하거나 켜지 않습니다. |
| 배포 환경 확인 | AI 응답 대기 20초와 호스팅의 서버 실행 시간 제한이 충돌하지 않는지, 무료 구간 한도 | 배포 단계에서 확인합니다. 지금은 확인하지 않았습니다. |
