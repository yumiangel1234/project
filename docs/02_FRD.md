# FRD — 현장별 공정·기성 대시보드

## 한눈에 보기

- 화면에서 무엇을 누르면 어떻게 동작하는지 17개 기능, 3개 역할, 6개 흐름, 계산 규칙 표로 정리했습니다.
- 월·지역·유형·현장 필터는 현황·추이·비교표·CSV·AI가 모두 같은 범위를 씁니다.
- 누적기성액(월말까지 쌓인 값)과 당월기성액(전월 누적과의 차액)은 따로 계산하고, 전월이 없으면 "계산 불가"입니다.
- 오류가 나면 어느 행의 무엇이 문제인지 알리고 지금 자료를 그대로 둡니다. AI가 실패해도 대시보드와 CSV는 계속 씁니다.
- `design/` 폴더가 비어 있어 시안을 확인하지 못했습니다. 화면 배치는 PRD의 "화면 요약"을 기준으로 썼고, 시안이 들어오면 대조합니다.

기준 문서: `01_PRD.md`, `실습조건.md`, `작업규칙.md`, `data/데이터설명.md`, `data/검산표.md`. `(AI 결정)`은 문서에 정해져 있지 않아 제가 정한 항목이며, 맨 아래 표에 모아 두었습니다.

## 1. 기능별 표

### 1-A. 자료 가져오기

| 번호 | 기능 | 사용자가 하는 일 | 프로그램이 하는 일 | 화면에 보이는 결과 | 오류·예외일 때 |
|---|---|---|---|---|---|
| 1 | 파일 고르고 검사 | "자료 가져오기" 페이지에서 CSV 또는 JSON 파일을 고릅니다. | 브라우저에서 파일을 읽고 15개 열 모두 필수인지, 값의 형식·범위, 같은 월·현장 중복, 현장 정보 일관성을 검사합니다(검사 항목은 3장 "가져오기 검사 규칙"). | 검사 중에는 "검사 중" 표시가 나옵니다. 통과하면 미리보기(기능 2)로 넘어갑니다. | 하나라도 어긋나면 반영하지 않습니다. "가져오기 오류" 화면에 파일 행 번호·열 이름·값·이유를 표로 보여 주고 "지금 자료는 그대로 유지됩니다"라고 안내합니다. 오류가 많으면 처음 20건과 "외 N건"을 보여 줍니다. 빈 칸을 0으로 바꾸지 않습니다. |
| 2 | 미리보기 후 가져오기 확인 | 미리보기를 보고 "가져오기"를 누릅니다. | 검사를 통과한 자료 전체로 지금 자료를 교체합니다. 이어붙이지 않습니다. 교체 후 월·지역·유형·현장 필터를 처음 상태(가장 최근 월·전체)로 되돌립니다. | 미리보기에 파일 형식·행 수·현장 수·월 범위와 처음 10행이 보입니다. 완료 화면에 "144행으로 교체했습니다"와 "현황 보기" 버튼이 나옵니다. 같은 자료를 CSV 다음 JSON으로 가져와도 144행입니다. | 월별 누락이 있으면 미리보기에 경고를 띄우고 "확인 가능한 행만 집계한다"고 알립니다(반영은 가능). CSV는 메타데이터가 없으므로 "단위는 백만원·%로 간주합니다"라고 안내합니다. JSON은 schemaVersion·단위·필수 열 정보를 확인하고, 다르면 오류로 거부합니다. |
| 3 | 가져오기 취소 | 미리보기나 오류 화면에서 "취소"를 누릅니다. | 읽은 내용을 버리고 지금 자료를 바꾸지 않습니다. | 자료 가져오기 첫 단계로 돌아가고 "지금 자료는 그대로입니다"가 보입니다. | 취소 후에도 9월 전체 기성률 67.2%·점검 3곳 같은 기존 화면 값이 그대로 유지됩니다. |

### 1-G. 상태 화면

| 번호 | 기능 | 사용자가 하는 일 | 프로그램이 하는 일 | 화면에 보이는 결과 | 오류·예외일 때 |

## 4. 계산 규칙 표

프로그램이 계산합니다. 원본 자료에 기성률·공정차이·상태를 저장하지 않습니다. 계산은 중간에 반올림하지 않고, 화면에 보이는 마지막 단계에서 소수 첫째 자리로 반올림합니다.

| 항목 | 계산 방법 | 예시 (검산표 숫자) |
|---|---|---|
| 현장 공정차이 | 실제공정률 − 계획공정률 (pp) | D, 2026-09: 75.8 − 86.5 = −10.7pp |
| 현장 상태 | 0pp 이상 정상 / −5pp 초과·0pp 미만 주의 / −5pp 이하 점검. 소수 첫째 자리 값을 10배 한 정수로 비교해 계산 오차를 막습니다 (AI 결정). | 계획 70·실제 70 → 정상, 실제 65.1 → 주의(−4.9), 실제 65 → 점검(−5.0) |
| 점검 순위 | 상태가 점검인 현장을 공정차이 오름차순, 같으면 현장 ID 오름차순으로 정렬 | 9월: D(−10.7) → I(−7.6) → K(−5.4) |
| 현장 기성률 | 누적기성액 ÷ 계약금액 × 100 | D, 9월: 50,384.4 ÷ 72,600 × 100 = 69.4% |
| 범위 전체 기성률 | 선택 월·범위의 누적기성액 합계 ÷ 같은 범위의 계약금액 합계 × 100 | 9월 전체: 424,063.4 ÷ 630,700 × 100 = 67.2% |
| 범위 계획·실제 공정률 | 현장 계약금액으로 가중평균: Σ(계약금액 × 공정률) ÷ Σ계약금액 | 9월 전체: 계획 73.2%, 실제 71.2% |
| 범위 공정차이 | 반올림 전 가중 실제 − 반올림 전 가중 계획. 화면에 보이는 두 공정률(반올림 값)을 다시 빼지 않습니다. | 9월 전체: −2.0pp (73.2 − 71.2가 아니라 반올림 전 값의 차) |
| 현장 당월기성액 | 같은 현장의 선택 월 누적기성액 − 바로 전월 누적기성액. 바로 전월 행이 있을 때만 계산합니다. | D, 9월: 50,384.4 − 47,044.8 = 3,339.6 (47,044.8은 원본 CSV의 D 8월 누적기성액) |
| 범위 당월기성액 | 범위의 모든 현장에 바로 전월 값이 있을 때만 현장 당월기성액을 합산합니다. 하나라도 없으면 계산 불가입니다. | 9월 전체: 424,063.4 − 395,184.7 = 28,878.7 |
| 첫 달·전월 없음 | 당월기성액 = 계산 불가(null). 0으로 바꾸거나 누적액으로 대신하지 않습니다. | 2025-10 전체: 계산 불가 (누적 105,449.7은 10월 기성이 아님) |
| 당월기성액 0 | 정상값입니다. 누락·계산 불가와 구별해 "0.0"으로 표시합니다. | J, 2026-07: 26,308.8 − 26,308.8 = 0.0 |
| 누적기성액과 당월기성액 구분 | 누적기성액은 월말까지 쌓인 값(월별로 합산하지 않음), 당월기성액은 한 달 증가분, 수금액은 자료에 없음 | 7월 누적 364,718.5 → 8월 395,184.7 → 9월 424,063.4, 8월 당월 30,466.2 |
| 월별 추이 | 선택한 지역·유형·현장 범위로 매월 따로 집계해 시작 월부터 선택 월까지 표시합니다. | 9월 전체: 12개월, 공정차이 0.2pp(10월) → −2.6pp(7월) → −2.0pp(9월) |
| 월별 상태 내역 | 선택 범위 현장의 상태를 월별로 센 값 | 9월: 정상 6·주의 3·점검 3 |
| 자료 없음 | 범위에 행이 없거나 분모(계약금액 합계)가 없으면 "계산 불가" | 0%로 대신하지 않음 |
| 표시 | %·pp·백만원은 소수 첫째 자리. 음수 영(−0.0)은 "0.0"으로 표시 (AI 결정) | 424,063.4 / 67.2% / −2.0pp |

| 파일 크기 한도 | 5MB 이하 | 144행 자료는 훨씬 작으므로 잘못된 큰 파일을 걸러 냅니다. |
| 추가 열 처리 | 15개 외의 열은 경고하고 무시 | 필수 열은 모두 읽고, 불필요한 열 때문에 거부하지 않기 위해서입니다. |
| 오류 표시 개수 | 처음 20건과 "외 N건" | 오류가 수백 건이어도 화면을 읽을 수 있게 합니다. |
| 미리보기 행 수 | 처음 10행 | 열 구성과 값 형식을 확인하기에 충분합니다. |
| 자료 교체 후 필터 | 가장 최근 월·전체로 초기화 | 이전 자료 기준의 월·현장이 남아 오류 나는 것을 막습니다. |
| 현장 목록 | 지역·유형 범위에 있는 현장만 표시 | 범위에 없는 현장을 고르는 일을 처음부터 막습니다. |
| 펼침 행 | 여러 줄 동시 펼침 가능 | 현장끼리 기록을 비교할 수 있습니다. |
| 비교표 정렬 | 현장 ID 순 | 점검 순서는 현황 요약의 순위가 맡습니다. |
| 상태 비교 방식 | 소수 첫째 자리를 10배한 정수로 비교 | 65.1 − 70 같은 계산의 미세한 오차로 판정이 뒤집히지 않게 합니다. |
| −0.0 표시 | "0.0" | 화면에 음수 영이 나오지 않게 합니다. |
| CSV 추가 열 이름·값 | `earnedRate`·`progressGap`·`status`·`monthlyEarned`, 소수 첫째 자리 | 원본 열 이름과 같은 방식이고 화면 숫자와 일치합니다. |
| CSV 파일 이름 | `현장공정기성_월[_현장].csv` | 어느 범위인지 이름으로 알 수 있습니다. |
| AI 전달 월별 요약 | 항상 함께 전송 | 추이 질문인지 가려내는 규칙을 따로 만들지 않아도 됩니다. |
| AI 월별 원문 기록 | 현장 한 곳 선택 시에만 전송 | 전송량을 줄이고 과거 월 원인을 지어내지 않게 합니다. |
| AI 질문 길이·시간 | 최대 500자, 응답 20초 | 비정상적으로 긴 입력과 무한 대기를 막습니다. |
