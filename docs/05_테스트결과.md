- 실제 Gemini 호출로 키와 모델 `gemini-3.8-flash`가 동작하고 정답 숫자대로 답하는 것을 확인했습니다. 키 없음·한도 초과 같은 실제 오류는 가짜 응답과 모의 모드로만 확인했습니다.
- 확인하지 못한 것: 사람의 화면 확인, 엑셀에서 한글 표시, 디자인 시안 대조(시안 없음), Edge 외 브라우저, 배포 환경.
- 기록일 2026-10-30. GitHub 저장과 Vercel 배포는 하지 않았습니다.

방법 표기: **자동 검사**(Vitest, 화면 없이 계산·검사 실행) / **자동 검사(브라우저)**(실제 Edge를 프로그램이 조작, 사람의 확인이 아님) / **실제 AI**(실제 Gemini 호출) / **모의 응답**(가짜 응답·`AI_MOCK`) / **사람의 화면 확인** / **미확인**.

## 4. 확인하지 못한 것

| 항목 | 이유·현재 상태 |
|---|---|
| 사람의 화면 확인 전체 | 아직 사용자가 확인하지 않았습니다. 레이아웃 깨짐, 글자 겹침, 색 대비, 읽기 쉬움은 자동 검사가 판단하지 못합니다. |
| 엑셀에서 한글 표시 | **미확인**. 파일이 UTF-8 BOM(EF BB BF)으로 시작하고 한글이 올바르게 들어 있음은 자동으로 확인했지만, 실제 엑셀에서 열어 보지는 않았습니다. |
| 디자인 시안 대조 | **미확인**. `design/` 폴더가 비어 있어 PRD의 화면 요약 기준으로 만들었습니다. |
| 키 없음·한도 초과·시간 초과의 실제 발생 | **미확인**(모의만). 가짜 응답(Vitest)과 `AI_MOCK` 모의 모드로 오류 분류와 화면 동작을 확인했지만, Google 서버가 실제로 그런 응답을 줄 때의 동작은 확인하지 못했습니다. |
| 실제 AI 답변의 일관성 | 답변은 호출마다 달라질 수 있습니다. 4개 예시 질문을 각 1회 실행한 결과이며, 반복 실행해도 같은 답이 나온다고 보장하지 못합니다. |
| Edge 외 브라우저 | **미확인**. Edge로만 확인했습니다(Chrome 등은 확인하지 않음). |
| 배포 환경(Vercel) | **미확인**. 배포하지 않았습니다. 응답 대기 20초와 호스팅의 실행 시간 제한, 무료 구간 한도는 배포 단계에서 확인해야 합니다. |
| 브라우저 새로고침 시 자료 | 설계상 새로고침하면 자료가 사라집니다(PRD "하지 않는 것"). 자동 검사는 앱 내부 이동만 사용했습니다. |

## 5. 개발 중 발견하고 고친 것

| 발견한 것 | 원인 | 조치 |
|---|---|---|
| 첫 실제 AI 호출에서 점검 순위 답변에 공정차이 숫자가 빠지고, 추이 답변에서 단위를 "%p"로 쓰고 0.5pp 변화를 언급하지 않음 | AI에게 순서·변화량을 맡긴 구조 | 점검 순위와 전월 대비 공정차이 변화를 프로그램이 계산해 전달하고, 지시문에 인용·단위 규칙을 추가했습니다(Vitest 2건 추가). 다시 호출해 정답대로 답하는 것을 확인했습니다. |
| 브라우저 검사 첫 실행에서 9건 실패 | 앱 결함이 아니라 검사 스크립트의 문제(화면 전환 직후 읽기, SVG 글자 읽기 방식, 투명 영역에 가린 점에 hover) | 스크립트를 고쳐 재실행해 33건 모두 통과했습니다. 콘솔의 404 한 건은 앱의 아이콘 파일 누락이라 아이콘을 추가했습니다. |
| 키 유출 점검 스크립트의 실수 | PowerShell에서 비교 기호 `>`가 파일 저장 기호로 동작해 프로젝트 폴더에 `0` 파일이 생기고, 점검이 형식적으로 통과함 | `0` 파일(키 길이 숫자만 담긴 7바이트)을 삭제하고, 키가 비어 있지 않음과 `.env.local`에 키가 있음(대조군)을 확인한 뒤 점검을 다시 했습니다. |
| 구현 중 기술 선택 변경 | 계획: 차트 Recharts, CSV 읽기·Gemini 연결은 "구현 시 선택" | 직접 만든 SVG, 직접 만든 CSV 읽기, REST 호출로 확정하고 `03_TRD.md`에 반영했습니다. |
